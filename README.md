# hx-bib

A tidy toolbox for BibTeX files: **format**, **clean**, **normalize venues**, **validate** and **verify citations**.

- **CLI** built with Typer + Rich — pretty, scriptable, CI-friendly.
- **GUI** built with NiceGUI — upload a `.bib` file and work through feature tabs in the browser.
- **Multi-source citation verification** against arXiv, Crossref, DBLP and OpenReview to catch hallucinated references.
